# 💢 پروژه کنترل کیفی دیسک ترمز 💢

### 🔰 کار های انجام شده :

1. در ناحیه صیقلی تشخیص ضایعات سطح و الگوریتم Area defect انجام بشه.
2. تشخیص وجود داشتن 4 سوراخ و دایره مرکزی توسط الگوریتم measurement
3. قطر دایره مرکزی
4. قطر هر کدام از 4 سوراخ ها
5. فاصله مراکز 4 سوراخ بصورت ضربدری از هم
6. بررسی قرار گرفتن مراکز دوایر سوراخ های طوق بیرونی نسبت به مرکز دایره‌ی وسط از لحاظ اینکه آیا بر روی یک دایره به شعاع ثابت قرار گرفتن یا خیر و محاسبه‌ی میزان انحراف هر یک در صورت وجود
7. مقایسه اندازه های اندازه گیری شده برنامه با ابعادی که استاد داده

- نکته: ابعاد و محاسبات برحسب دهم میلی متر است.

### 📝 ابعاد داده شده توسط استاد :

- قطر هر سوراخ 10 میلی متر است.
- قطر دایره مرکزی 75 میلی متر است.
- فاصله ضربدری سوراخ به سوراخ 93 میلی متر است.

## 🏗 ساختار پروژه

```
Brake-disc-quality-control/
│
├── img/
│   └── disc.jpg               # تصویر پیش فرض ورودی
│
├── outputs/
│   ├── defect_mask.jpg        # ماسک نهایی تشخیص لکه‌های تشخیص‌داده‌شده سفید هستند
│   ├── inspection_result.jpg  # تصویر اصلی با مستطیل‌های قرمز دور ضایعات
│   ├── polished_mask.jpg      # فقط محدوده‌ای که برای کنترل سطح بررسی شده است
│   └── roi.jpg                # ناحیه صیقلی خاکستری همراه با لکه‌های واقعی
│
├── brake_disc_qc.py           # فایل اصلی برنامه
├── camera.py                  # برای تصویر برداری آنلاین با دوربین گوشی
├── README.md
└── requirements.txt           # وابستگی های لازم
```

## 📝 نحوه اجرا

### 1. دانلود پوشه `Brake-disc-quality-control`

### 2. نصب وابستگی‌ها

```bash
pip install -r requirements.txt
```

### 3. اگر تصویر ورودی آپلودی است در پوشه `img` با نام `disc.jpg` قرار دهید و فایل `brake_disc_qc.py` را اجرا کنید.

```bash
python brake_disc_qc.py
```

### 4. اگر با دوربین میخواد تصویر گرفته بشه فایل `camera.py` رو اجرا کنید.

```bash
python camera.py
```

### 📍 برای اجرای فایل `camera.py` باید قبلش روی سیستم و گوشی نرم افزار DroidCam نصب شده باشه.
